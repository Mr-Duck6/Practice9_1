# Todo Application with Local Persistence

Опис: Повнофункціональний Todo-додаток. Проєкт підтримує локальне збереження даних за допомогою SharedPreferences через JSON-серіалізацію, має гнучку систему фільтрації, сортування, статистику та зручний UI/UX.

---

## Основні можливості та функціонал

### 1. Управління задачами

- Створення: Додавання нових задач із назвою, описом, категорією, рівнем пріоритету та кастомними тегами.
- Читання: Відображення списку задач у вигляді адаптивного ListView.
- Оновлення: Зміна статусу виконання та автофіксація часу завершення.
- Видалення: Швидке видалення задачі за допомогою свайпу вліво.

### Фільтрація та Сортування

- Фільтрація за категорією: Обирайте конкретну категорію за допомогою зручних FilterChip.
- Фільтрація за статусом: Відображення усіх задач, лише активних або лише виконаних.
- Сортування:
  - Спочатку нові (за датою створення вниз);
  - Спочатку старі (за датою створення вгору);
  - За пріоритетом (від високого до низького).

### Статистика

Окремий екран аналітики, який показує:

- Загальну кількість задач;
- Кількість виконаних та активних задач;
- Деталізований розподіл задач за категоріями.

### Додаткові фічі

- Undo (Скасування видалення): При видаленні задачі відображається SnackBar з можливістю миттєвого відновлення.
- Batch Delete: Можливість очистити всі виконані задачи в один клік через AppBar.
- Автозбереження: Будь-які зміни (створення, редагування статусу, видалення) миттєво синхронізуються з локальним сховищем пристрою.
